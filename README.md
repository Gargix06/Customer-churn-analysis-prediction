# Customer Churn Analysis and Prediction

## Project Overview

This project focuses on analysing customer churn in a telecommunications company and predicting whether a customer is likely to leave the service using Machine Learning.

The project uses Python for data preprocessing, exploratory data analysis, feature selection, model training, and evaluation.

**Internship:** SaiKet Systems

## Objectives

- Understand customer churn patterns.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Identify important features affecting customer churn.
- Build and compare Machine Learning classification models.
- Evaluate model performance using different metrics.

## Dataset

The project uses a Telco Customer Churn dataset containing 7,043 customer records and 21 columns.

The target variable is `Churn`, which indicates whether a customer has left the company.

- Yes: Customer churned.
- No: Customer stayed.

## Machine Learning Algorithms

The following classification algorithms are compared:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

The models are compared using 5-fold cross-validation with F1-score.

## Evaluation Metrics

The selected model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score
- Confusion Matrix
- ROC Curve

## How to Run the Project

1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Upload the Telco Customer Churn CSV dataset to the Colab session.
4. Update the dataset file path in the data-loading cell if necessary.
5. Run the notebook cells in order.
6. Review the generated visualisations and model evaluation results.

## Expected Outcome

The project aims to identify customer churn patterns and develop a classification model that can help businesses understand customer retention and identify customers who may be likely to leave.
